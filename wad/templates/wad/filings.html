Files

{% explainer "files-help" beside %}

Each file is the bytes as they were generated, kept for the same reason an invoice's XML is kept: the register is rebuilt from invoices every time it is read, so the file generated one May is not necessarily the file the same code renders two years later.

One is checked against the published JPK_EWP(4) schema before it is kept, so a file that would be rejected at filing time is refused here instead. An empty year has none at all: the file states how many rows it carries and the schema requires at least one.

A year may hold several. The first carries CelZlozenia 1 and every one after it 2 - the first submission for a period can only be made once, and a correction is itself a thing that was filed, so it supersedes without replacing. One generated by mistake can be discarded, but not one recorded as filed.
